## Details

### 🐺 Werewolf
Wolvesville-inspired social-deduction game with bot opponents, full night/day phases, many roles, a shop, avatars and profile. Original name and art. Playable in the browser at phone width.

### 🚪 The Knock
A 5-night survival game where you decide who to let in. Built for the Digit7 Jam 2026, with both a 3D (Three.js) and a 2D (Phaser) version.

### 🃏 Uno Game
First-year Python term project (KMITL Software Engineering): a small GUI game where you pick the card the program secretly chose, against an AI or with friends.

### 🦖 T-rex
A T-rex game written in assembly for a Computer Organization and Architecture course (KMITL, Year 2).
